# UX Flows (Draft)

This document captures high-level UX flows for the V3 wizard, based on Miro boards.

## Wizard Overview

- 7-step top rail (Ingestion → Translation → Normalization → Scoring → Persistence → Enrichment → Analytics).
- Single-page layout with:
  - Top rail
  - Middle content area
  - Bottom status bar and actions
  - Right side drawer for AI explanations and patches (when applicable).
